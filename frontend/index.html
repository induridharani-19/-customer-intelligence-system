System Architecture

How the Customer Intelligence System works

A complete ML pipeline from raw transaction data to actionable segment recommendations — built with Python, scikit-learn, TensorFlow, and FastAPI.

Data Pipeline

End-to-end flow

1. Data Ingestion

UCI Online Retail dataset (541,909 transactions) is downloaded and cached locally. Each record has Invoice, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country.

→

2. Preprocessing

Remove nulls, filter valid CustomerIDs, drop negative quantities (returns), parse dates. Resulting in ~4,338 clean customers.

→

3. Feature Engineering

Build RFM + features per customer: Recency (days since last order), Frequency (log transaction count), MonetaryValue (log total spend), TotalQuantity (log items bought), AvgUnitPrice (mean product price).

→

4. K-Means Clustering

K-Means evaluated for K=2…10 using Inertia (elbow method) and Silhouette Score. Optimal K=4 selected (score=0.356). Customers assigned to 4 behavioural segments.

→

5. Neural Network

A small TensorFlow/Keras classifier trained on cluster labels: 5-dim input → Dense(64, ReLU) → customer_embedding(32) → Dense(16) → Softmax(4). Learns compact customer representations.

→

6. API + Dashboard

FastAPI serves real-time predictions at /api/predict. This dashboard calls it live — every slider change triggers inference within ~400 ms via debounced auto-predict.

Input Features

What the 5 sliders mean

R
Recency

How many days ago the customer last made a purchase. Lower = more recent = higher engagement. Range: 0–500 days.

F
Frequency

Log-transformed count of total transactions. Higher = loyal repeat buyer. Range: 0–10 (log scale, so 4.9 ≈ 134 transactions).

M
Monetary Value

Log-transformed total spend. Higher = more valuable customer. Range: 0–15 (log scale, so 7.9 ≈ £2,697).

Q
Total Quantity

Log-transformed count of total items purchased. Distinguishes bulk buyers from premium buyers.

P
Avg Unit Price

Mean price per item across all their orders. High values indicate premium/luxury shoppers. Cluster 2 centroid is £2,033.

Segments

What each cluster means

0
Regular Buyers

Moderate recency, medium frequency & spend. Core customer base. Strategy: upsell and increase basket size.

1
Premium Customers

Low recency (very recent), high frequency, highest monetary value. Your best customers. Strategy: loyalty perks, early access.

2
High-Value Niche

Infrequent buyers (low frequency) but extremely high avg unit price (£2,033). Luxury shoppers. Strategy: personalised boutique service.

3
Dormant / At-Risk

High recency (248+ days ago), low frequency. At risk of churn. Strategy: reactivation campaigns, win-back offers.
